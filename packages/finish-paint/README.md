# finish-paint

`@level-designer/finish-paint` owns the arithmetic of the dark factory's procedural
materials: the arithmetic interface that the layer kinds are written over, its number back
end, and the layer kinds themselves. It depends on no workspace package, and its source is
browser-safe. `@level-designer/level-view` supplies the node back end and draws the
painters.
