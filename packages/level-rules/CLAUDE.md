# level-rules rules

- Keep every check a pure function over the five facts of a built level: the typed
  description, the typed level, the GLB inspection, the base stage's image count and the
  prepared static level. Read no file and run no level preparation.
- Judge the outcome of sec-111's preparation; copy none of sec-111's numbers.
- Spell each finding's rule id, subject and message as the level format document states
  them. Decide by the rule id, never by the message text.
- Compare every length limit with `LENGTH_SLACK` and render every length of a message with
  `formatLength`, both of `@level-designer/level-format`; hold no copy of either.
- Construct a slab's destruction lib model only through `@level-designer/slab-model`'s
  shared builder, and reach destruction lib only through
  `@level-designer/destruction-gateway`.
- Read a slab's box and corners through `@level-designer/level-format`, the floor under a
  point through `@level-designer/sec111-gateway` and the GLB facts as
  `@level-designer/level-glb` types them.
- Never let a page import this component: it reaches destruction lib, whose Rapier copy
  must not meet sec-111's in a page bundle.
- Test on sec-111's committed prepared level through the gateway's testing entry or on a
  hand-built box room. Never prepare a level in a test; `level-pipeline` owns the
  preparations.
